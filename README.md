Project Description:

Matrix Chain Multiplication Optimization using Interval Dynamic Programming is a project that finds the most efficient way to multiply a sequence of matrices. Since matrix multiplication is associative, the matrices can be grouped in different ways, but each grouping can require a different number of scalar multiplications.
The project uses Interval Dynamic Programming (DP) to evaluate different multiplication orders and determine the one with the minimum computational cost. The system takes the dimensions of the matrices as input, constructs a DP table, calculates the minimum number of multiplications required, and displays the optimal parenthesization/order.

Expected Outcomes:

Determine the minimum number of scalar multiplications required.
Find the optimal order of matrix multiplication.
Implement Interval Dynamic Programming to solve the optimization problem.
Display the DP table showing the calculated costs for different matrix intervals.
Reduce unnecessary computations compared with checking all possible multiplication orders.
Demonstrate how dynamic programming improves computational efficiency.
Provide a clear understanding of optimal substructure and overlapping subproblems in matrix chain multiplication.
